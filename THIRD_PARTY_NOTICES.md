# Third-party notices

## Alfis

The `bin/alfis` file in the release archive is an unmodified build of
[Alfis](https://github.com/Revertron/Alfis) v0.10.0, configured with the `webui`
and `doh` features and without the desktop GUI. X-Node runs it as
`x-node-dns.service`.

<https://github.com/Revertron/Alfis/blob/v0.10.0/LICENSE>.

The corresponding source code is published with this release as
`alfis-v0.10.0-source.tar.gz`, and is also available from the upstream tag:
<https://github.com/Revertron/Alfis/archive/refs/tags/v0.10.0.tar.gz>.
