## Alfis

The `bin/alfis` file in the release archive is an unmodified build of
[Alfis](https://github.com/Revertron/Alfis) 0.10.0 from upstream commit
`4427af35fc138a6b05cc9a9ebe11da3631cae15a`, configured with the `webui` and
`doh` features and without the desktop GUI. X-Node runs it as
`x-node-dns.service`.
